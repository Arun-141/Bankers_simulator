# Banker's Algorithm Simulator

An interactive web app that teaches and simulates the Banker's Algorithm
for deadlock avoidance in Operating Systems.

**Live demo:** https://bankers-algorithm-simulation-by-arun.netlify.app

## Features
- Animated landing page with an OS-themed background
- Interactive tutorial that explains the algorithm first
- Dynamic Allocation, Maximum and Available input tables
- Automatic Need matrix calculation
- Step-by-step safety algorithm with animated process completion
- Safe sequence display and clear unsafe-state detection
- Resource-request test (grant or deny)
- Example datasets, input validation and Reset

## Tech stack
HTML, CSS, JavaScript (no frameworks)

## Run locally
Download the files and open `index.html` in a browser.
